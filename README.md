# Comrade

Comrade is a financial management application designed to help users manage savings, loans, and track their finances. It includes a user-friendly interface for regular users and an administrative dashboard for managing system-wide activities like loan approvals.

## Features

- **User Authentication**: Secure login and registration for users.
- **Admin Dashboard**: Specialized access for administrators to oversee operations.
- **Savings Management**: Track individual and group savings.
- **Loan Management**: Apply for loans and monitor status.
- **Financial Tracker**: Manage and visualize daily transactions.
- **Navigation**: Built with Jetpack Navigation for seamless transitions.

## Tech Stack
- **Kotlin**: Primary programming language.
- **Android Architecture Components**: ViewModel, LiveData, Navigation Component.
- **View Binding**: For safe interaction with UI elements.
- **Material Design**: For a modern and responsive UI.

## Getting Started
1. Clone the repository.
2. Open in Android Studio.
3. Build and run on an emulator or physical device.
